# 对象使用

执行下面的代码，使用不同访问修饰符来控制类成员的可访问性。

```typescript
class Person {
    public name: string;
    protected age: number;
    constructor(name: string, age: number) {
        this.name = name;
        this.age = age;
    }
}
class SmartPerson extends Person {
    private gender: string;
    constructor(name: string, age: number, gender: string) {
        super(name, age);
        this.gender = gender;
    }
    public func1(): void {
        console.log(this.age);
    }
    public func2(): void {
        console.log(this.gender);
    }
}
let Tom: Person = new Person('Tom', 20);
console.log(Tom);
let Jerry: SmartPerson = new SmartPerson('Jerry', 18, 'female');
console.log(Jerry);
Jerry.func1();
Jerry.func2();
```

也可以在构造函数参数上直接指定访问修饰符， TypeScript 将自动声明成员变量并赋值。

```typescript
class Person {
    constructor(
        public name: string,
        protected age: number,
        private gender: string
    ) {
        console.log(this.name, this.age, this.gender);
    }
}
let Tom: Person = new Person('Tom', 20, 'female');
```

执行下面的代码，标记类的属性只读，只能在声明处或者构造函数里赋值，之后不能修改。

```typescript
class Person {
    constructor(
        public name: string,
        protected readonly age: number = 18
    ) {
        console.log(this.name, this.age);
    }
}
let Tom: Person = new Person('Tom', 20);
```
