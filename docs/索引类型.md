# 索引类型

执行下面的代码，使用索引类型动态访问指定对象的属性。

```typescript
interface Person {
    name: string,
    age: number,
    gender: string
}

function getProperty<T, U extends keyof T>(obj: T, key: U): T[K] {
    return obj[key];
}

let Tom: Person = {
    name: 'Tom',
    age: 20,
    gender: 'male'
};
console.log(Tom);
console.log(getProperty(Tom, 'name'));
console.log(getProperty(Tom, 'age'));
console.log(getProperty(Tom, 'gender'));
```
