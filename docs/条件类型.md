# 条件类型

条件类型是 TypeScript 类型层面的三元分支判断，是实现高级类型编程、类型提取、类型过滤的核心基础。

```typescript
type ConditionT<T> = T extends string ? 'Hello TypeScript!' : 233;
type UnknownT1 = ConditionT<'Hello World!'>;  // 'Hello TypeScript!'
type UnknownT2 = ConditionT<666>;             // 233
```

也可以在条件判断过程中声明临时类型变量，让 TypeScript 自动推断并获取目标类型。

```typescript
type ReturnT<T> = T extends (...args: any[]) => infer U ? U : never;
type UnknownT1 = ReturnT<(x: number, y: number) => number>;  // number
type UnknownT2 = ReturnT<(x: number, y: string) => string>;  // string
```
