# 泛型约束

泛型允许使用类型参数来批注未指定的变量类型，等待具体使用时才指定具体类型。

```typescript
function func<T>(data: T): T {
    return data;
}
console.log(func<string>('foo'));
console.log(func<number>(233));
```

泛型可以应用于类的实例变量和方法。

```typescript
class Demo<T> {
    constructor(
        public data: T
    ) {
        console.log(this.data, typeof this.data);
    }
}
let foo: Demo<string> = new Demo<string>('foo');
console.log(foo);
let bar: Demo<number> = new Demo<number>(233);
console.log(bar);
```

也可以使用泛型来定义接口，使接口的成员能够使用任意类型。

```typescript
interface Demo<T, U> {
    foo: T,
    bar: U
}
let obj1: Demo<string, number> = {
    foo: 'foo',
    bar: 233
}
console.log(obj1);
let obj2: Demo<number, string> = {
    foo: 233,
    bar: 'bar'
}
console.log(obj2);
```

还可以使用泛型约束进一步限制泛型的类型范围。

```typescript
function func<T extends { length: number }>(arg: T): number {
    return arg.length;
}
console.log(func<string>('233'));
console.log(func<number[]>([1, 2, 3]));
```
