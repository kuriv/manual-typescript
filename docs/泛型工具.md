# 泛型工具

执行下面的代码，将指定类型中所有属性变为可选。

```typescript
interface Person {
    name: string,
    age: number,
    gender: string
}
type PartialT = Partial<Person>;
let Tom: Person = {
    name: 'Tom',
    age: 20,
    gender: 'male'
};
console.log(Tom);
let Jerry: PartialT = {
    name: 'Jerry'
};
console.log(Jerry);
```

执行下面的代码，将指定类型中所有属性变为必填。

```typescript
interface Person {
    name?: string,
    age?: number,
    gender?: string
}
type RequiredT = Required<Person>;
let Tom: Person = {
    name: 'Tom'
};
console.log(Tom);
let Jerry: RequiredT = {
    name: 'Jerry',
    age: 18,
    gender: 'female'
};
console.log(Jerry);
```

执行下面的代码，将指定类型中所有属性变为只读。

```typescript
interface Person {
    name: string,
    age: number,
    gender: string
}
type ReadonlyT = Readonly<Person>;
let Tom: Person = {
    name: 'Tom',
    age: 20,
    gender: 'male'
};
Tom.age++;
console.log(Tom);
let Jerry: ReadonlyT = {
    name: 'Jerry',
    age: 18,
    gender: 'female'
};
console.log(Jerry);
```

执行下面的代码，从指定类型中挑选若干属性来组成新的类型。

```typescript
interface Person {
    name: string,
    age: number,
    gender: string
}
type PickT = Pick<Person, 'name' | 'age'>;
let Tom: Person = {
    name: 'Tom',
    age: 20,
    gender: 'male'
};
console.log(Tom);
let Jerry: PickT = {
    name: 'Jerry',
    age: 18
};
console.log(Jerry);
```

执行下面的代码，从指定类型中排除若干属性来组成新的类型。

```typescript
interface Person {
    name: string,
    age: number,
    gender: string
}
type OmitT = Omit<Person, 'age' | 'gender'>;
let Tom: Person = {
    name: 'Tom',
    age: 20,
    gender: 'male'
};
console.log(Tom);
let Jerry: OmitT = {
    name: 'Jerry'
};
console.log(Jerry);
```

执行下面的代码，根据指定的键和值构造新的对象类型。

```typescript
type RecordT = Record<string, number>;
let obj: RecordT = {
    foo: 233,
    bar: 666
};
console.log(obj);
```

执行下面的代码，从联合类型中排除若干类型来返回新的类型。

```typescript
type Union = 'foo' | 'bar' | 'baz' | number;
type ExcludeT = Exclude<Union, 'foo' | 'bar'>;
let result: ExcludeT;
result = 'baz';
console.log(result);
result = 233;
console.log(result);
```

执行下面的代码，从联合类型中提取若干类型来返回新的类型。

```typescript
type Union = 'foo' | 'bar' | 'baz' | number;
type ExtractT = Extract<Union, string>;
let result: ExtractT;
result = 'foo';
console.log(result);
result = 'bar';
console.log(result);
result = 'baz';
console.log(result);
```

执行下面的代码，从联合类型中排除空类型来返回新的类型。

```typescript
type Union = string | undefined | null;
type NonNullableT = NonNullable<Union>;
let result: NonNullableT;
result = 'foo';
console.log(result);
```

执行下面的代码，将字符串字面量全部转为大写。

```typescript
console.log(result);
result = 'SPIKE';
console.log(result);
```
