# 抽象类

抽象类是一种不能被直接实例化的类，主要用于为子类提供统一的结构和行为模板。

```typescript
abstract class Person {
    constructor(
        public name: string,
        protected age: number
    ) {
        console.log(this.name, this.age);
    }
    public func1(): void {
        console.log(this.age);
    }
    abstract func2(): void;
}
class SmartPerson extends Person {
    func2(): void {
        console.log(this.name, this.age);
    }
}
let Tom: SmartPerson = new SmartPerson('Tom', 20);
Tom.func1();
Tom.func2();
```
