# 方法重写

执行下面的代码，子类覆盖父类同名方法，替换父类原有逻辑。

```typescript
class Person {
    func(): void {
        console.log('Hello World!');
    }
}
class SmartPerson extends Person {
    override func(): void {
        console.log('Hello TypeScript!');
    }
}
let Tom: Person = new Person();
Tom.func();
let Jerry: SmartPerson = new SmartPerson();
Jerry.func();
```
