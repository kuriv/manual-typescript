类型批注

类型批注

执行下面的代码，批注数值类型变量，包括整数和浮点数。

let num: number = 233;
console.log(num, typeof num);

执行下面的代码，批注字符串类型变量。

let str: string = 'Hello TypeScript!';
console.log(str, typeof str);

执行下面的代码，批注布尔类型变量。

let bool: boolean = true;
console.log(bool, typeof bool);

执行下面的代码，批注未定义类型变量。

let undef: undefined;
console.log(undef, typeof undef);

执行下面的代码，批注空类型变量。

let NULL: null = null;
console.log(NULL, typeof NULL);

执行下面的代码，批注非原始类型变量，适用于复杂对象结构。

let obj: object = {
    name: 'Tom',
    age: 20
};
console.log(obj, typeof obj);

执行下面的代码，批注可选参数。

let obj: {
    name: string,
    age?: number
};
obj = {
    name: 'Tom'
};
console.log(obj, typeof obj);

执行下面的代码，批注数组类型变量，用于表示一组相同类型的元素。

let arr1: number[] = [1, 2, 3, 4, 5];
console.log(arr1, typeof arr1);
let arr2: Array<string> = ['foo', 'bar', 'baz'];
console.log(arr2, typeof arr2);

执行下面的代码，批注元组类型变量，每个元素可以是不同的类型。

let tuple: [string, number] = ['foo', 233];
console.log(tuple, typeof tuple);

执行下面的代码，批注枚举类型变量，默认情况下枚举的值从 0 开始递增。

enum direction { up, down, left, right }
console.log(direction);
let up: direction = direction.up;
console.log(up, typeof up);
let down: direction = direction.down;
console.log(down, typeof down);
let left: direction = direction.left;
console.log(left, typeof left);
let right: direction = direction.right;
console.log(right, typeof right);

执行下面的代码，批注联合类型变量，满足其中任意一个类型即可。

let union: number | string;
union = 233;
console.log(union, typeof union);
union = 'Hello TypeScript!';
console.log(union, typeof union);

执行下面的代码，批注交叉类型变量，必须同时满足所有类型的要求。

let obj: { name: string } & { age: number };
obj = {
    name: 'Tom',
    age: 20
};
console.log(obj, typeof obj);

执行下面的代码，批注字面量类型，使变量只能拥有特定的值。

let direction: 'up' | 'down' | 'left' | 'right';
direction = 'up';
console.log(direction, typeof direction);

执行下面的代码，批注任意类型变量。注意，任意类型将绕过对变量的类型检查。

let foo: any = 233;
console.log(foo, typeof foo);
foo = 'Hello TypeScript!';
console.log(foo, typeof foo);

执行下面的代码，批注未知类型变量。注意，必须经过类型检查后才能进行赋值。

let foo: unknown = 233;
console.log(foo, typeof foo);
foo = 'Hello TypeScript!';
console.log(foo, typeof foo);

执行下面的代码，批注空类型，主要用于没有返回值的函数。

function func(): void {
    console.log('Hello TypeScript!');
}
func();

执行下面的代码，批注不存在类型，表示永远不会有返回值。

function func(): never {
    throw new Error('foo');
}
func();
