# 泛型工具

执行下面的代码，将指定类型中所有属性变为可选。

```typescript
interface Person {
    name: string,
    age: number,
    gender: string
}
type PartialType = Partial<Person>;
let Tom: Person = {
    name: 'Tom',
    age: 20,
    gender: 'male'
};
console.log(Tom);
let Jerry: PartialType = {
    name: 'Jerry'
};
console.log(Jerry);
```

执行下面的代码，将指定类型中所有属性变为必填。

```typescript
interface Person {
    name?: string,
    age?: number,
    gender?: string
}
type RequiredType = Required<Person>;
let Tom: Person = {
    name: 'Tom'
};
console.log(Tom);
let Jerry: RequiredType = {
    name: 'Jerry',
    age: 18,
    gender: 'female'
};
console.log(Jerry);
```

执行下面的代码，将指定类型中所有属性变为只读。

```typescript
interface Person {
    name: string,
    age: number,
    gender: string
}
type ReadonlyType = Readonly<Person>;
let Tom: Person = {
    name: 'Tom',
    age: 20,
    gender: 'male'
};
Tom.age++;
console.log(Tom);
let Jerry: ReadonlyType = {
    name: 'Jerry',
    age: 18,
    gender: 'female'
};
console.log(Jerry);
```

执行下面的代码，从指定类型中挑选若干属性来组成新的类型。

```typescript
interface Person {
    name: string,
    age: number,
    gender: string
}
type PickType = Pick<Person, 'name' | 'age'>;
let Tom: Person = {
    name: 'Tom',
    age: 20,
    gender: 'male'
};
console.log(Tom);
let Jerry: PickType = {
    name: 'Jerry',
    age: 18
};
console.log(Jerry);
```

执行下面的代码，从指定类型中排除若干属性来组成新的类型。

```typescript
interface Person {
    name: string,
    age: number,
    gender: string
}
type OmitType = Omit<Person, 'age' | 'gender'>;
let Tom: Person = {
    name: 'Tom',
    age: 20,
    gender: 'male'
};
console.log(Tom);
let Jerry: OmitType = {
    name: 'Jerry'
};
console.log(Jerry);
```

执行下面的代码，根据指定的键和值构造新的对象类型。

```typescript
type RecordType = Record<string, number>;
let obj: RecordType = {
    foo: 233,
    bar: 666
};
console.log(obj);
```

执行下面的代码，从联合类型中排除若干类型来返回新的类型。

```typescript
type Union = 'foo' | 'bar' | 'baz' | number;
type ExcludeType = Exclude<Union, 'foo' | 'bar'>;
let result: ExcludeType;
result = 'baz';
console.log(result);
result = 233;
console.log(result);
```

执行下面的代码，从联合类型中提取若干类型来返回新的类型。

```typescript
type Union = 'foo' | 'bar' | 'baz' | number;
type ExtractType = Extract<Union, string>;
let result: ExtractType;
result = 'foo';
console.log(result);
result = 'bar';
console.log(result);
result = 'baz';
console.log(result);
```

执行下面的代码，从联合类型中排除空类型来返回新的类型。

```typescript
type Union = string | undefined | null;
type NonNullableType = NonNullable<Union>;
let result: NonNullableType;
result = 'foo';
console.log(result);
```

执行下面的代码，将字符串字面量全部转为大写。

```typescript
let result: UppercaseType;

console.log(result);

console.log(result);
result = 'SPIKE';
console.log(result);
```
