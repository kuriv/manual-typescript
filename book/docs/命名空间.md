# 命名空间

命名空间是 TypeScript 提供的作用域代码分组机制，用于避免全局环境的命名冲突。

```typescript
namespace Demo {
    export function func(): void {
        console.log('Hello World!');
    }
    export const num: number = 233;
    export let str: string = 'Hello TypeScript!';
    let bool: boolean = true;
}
Demo.func();
console.log(Demo.num);
console.log(Demo.str);
```

命名空间支持多层嵌套，实现更细的代码分层。

```typescript
namespace Foo {
    export namespace Bar {
        export function func(): void {
            console.log('Hello World!');
        }
    }
    export namespace Baz {
        export function func(): void {
            console.log('Hello TypeScript!');
        }
    }
}
Foo.Bar.func();
Foo.Baz.func();
```

执行下面的代码，同一作用域下多个同名的命名空间会自动合并成员。

```typescript
namespace Demo {
    export function func(): void {
        console.log('Hello World!');
    }
}
namespace Demo {
    export const num: number = 233;
}
namespace Demo {
    export let str: string = 'Hello TypeScript!';
}
Demo.func();
console.log(Demo.num);
console.log(Demo.str);
```

还可以专门创建用于存放全局类型声明的文件，为 TypeScript 编译器补充全局作用域下的类型定义，只提供类型校验和代码提示，不会生成任何实际的 JavaScript 代码，编辑 `global.d.ts` 文件内容如下。

```typescript
declare namespace Demo {
    export function func(): void;
    export const num: number;
    export let str: string;
}
```
