# 函数重载

执行下面的代码，为一个函数定义多个签名，根据传入的参数类型选择正确的实现。

```typescript
function func(str: string): void;
function func(num: number): void;
function func(arg: string | number): void {
    if (typeof arg === 'string') {
        console.log(arg.toUpperCase());
    } else {
        console.log(arg ** 2);
    }
}
func('foo');
func(233);
```

执行下面的代码，为一个函数定义定义多个参数的不同组合。

```typescript
function func(str: string): void;
function func(str: string, num: number): void;
function func(str: string, num ?: number): void {
    if (num !== undefined) {
        console.log(str, num);
    } else {
        console.log(str);
    }
}
func('foo');
func('foo', 233);
```

还可以对类中的方法进行重载。

```typescript
class Demo {
    func(str: string): void;
    func(num: number): void;
    func(arg: string | number): void {
        if (typeof arg === 'string') {
            console.log(arg.toUpperCase());
        } else {
            console.log(arg ** 2);
        }
    }
}
let obj: Demo = new Demo();
obj.func('foo');
obj.func(233);
```
