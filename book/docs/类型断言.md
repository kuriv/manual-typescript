# 类型断言

执行下面的代码，通过类型断言手动指定变量类型，常用于无法推断的情况。

```typescript
let foo: unknown = 'Hello TypeScript!';
console.log(foo, typeof foo);
let bar: string = foo as string;
console.log(bar, typeof bar);
```

也可以执行下面的代码来实现类型断言。

```typescript
let foo: unknown = 'Hello TypeScript!';
console.log(foo, typeof foo);
let bar: string = <string>foo;
console.log(bar, typeof bar);
```
