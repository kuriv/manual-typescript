接口

接口是一种类型声明机制，仅描述成员的名称、类型，而不提供任何具体实现代码。

interface Person {
    name: string,
    age: number,
    func(): void
}
let Tom: Person = {
    name: 'Tom',
    age: 20,
    func(): void {
        console.log('Hello TypeScript!');
    }
};
console.log(Tom);
Tom.func();

接口也可以通过继承其他接口来扩展自己。

interface PersonAge {
    age: number
}
interface PersonGender {
    gender: string
}
interface Person extends PersonAge, PersonGender {
    name: string
}
let Tom: Person = {
    name: 'Tom',
    age: 20,
    gender: 'male'
};
console.log(Tom);

在同一个作用域定义多个同名接口， TypeScript 会自动将它们的成员合并为一个接口。

interface Person {
    name: string
}
interface Person {
    age: number
}
interface Person {
    gender: string
}
let Tom: Person = {
    name: 'Tom',
    age: 20,
    gender: 'male'
};
console.log(Tom);

执行下面的代码，要求类完整实现接口的全部定义。

interface PersonAge {
    age: number
}
interface PersonGender {
    gender: string
}
class Person implements PersonAge, PersonGender {
    constructor(
        public name: string,
        public age: number,
        public gender: string
    ) {
        console.log(this.name, this.age, this.gender);
    }
}
let Tom: Person = new Person('Tom', 20, 'female');
console.log(Tom);
